# Student Form App

A responsive frontend web app for student enrollment data entry.

## Run

Open `index.html` directly in a browser, or run a simple local server from this folder:

```powershell
python -m http.server 5500
```

Then open: `http://localhost:5500`

## Features

- Student enrollment form with required field validation
- Email, phone, and ZIP pattern checks
- Submission preview card
- Responsive design for desktop and mobile
